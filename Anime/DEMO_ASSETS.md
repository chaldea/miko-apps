# 演示数据与图片

更新日期：2026-11-10。来源为当前 Lanerc 只读 API 的首页、排行、排期和番剧详情，不使用账号资料或用户评论。

- 共 28 部番剧，包含首页热门与两类目录、三个排行分组、七天排期以及可切换的线路和分集。
- 共 31 张图片：番剧封面和首页横幅均来自 API 返回的原图地址，不再从截图截取。图片等比例缩小，最长边不超过 720 像素，WebP 质量 85；没有裁切或强行改变宽高比。所选图片全部成功下载，无远程图片依赖。
- 目录和详情在 `MikoApp.Anime/Assets/Demo/snapshot.json`，资源使用 `res://Assets/Demo/...`。快照只保留展示需要的字段，分集的 `resource_id` 全部替换为 `demo-video`。
- 所有分集使用仓库唯一的 `Assets/sample.mp4`；不打包整集视频、真实播放 URL、令牌、密码或代理凭据。
- 评论与账号操作是本机会话中的演示数据，不复制真实用户内容；模式切换时清除。观看与搜索记录按模式/服务器分开保存。

更新命令：`dotnet run --project Anime/MikoApp.Anime.Verification -- --refresh-demo`。只调用只读目录和详情接口，按小样本选取（每类首页 6 条、每个排行 2 条、每天排期 1 条，加首页热门和横幅关联条目，按 ID 去重）。不会调用播放地址解析。每次在 `Anime/artifacts/demo-capture/` 新建独立采集目录，避免后续刷新误用旧快照；已存在的图片按 URL 哈希复用。导出后清理专用 Demo 目录中不再引用的图片。

第三方元数据与图片的权利归各自所有者，适用仓库 README 的第三方资源说明。
